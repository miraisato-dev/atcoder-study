# ABC441 A問題

## 問題
URL: https://atcoder.jp/contests/abc441/tasks/abc441_a

## 考察
・黒く塗られているのは左上が (P, Q) の 100 × 100 の長方形
・黒マスの範囲は行方向：P ≤ X ≤ P + 99、列方向：Q ≤ Y ≤ Q + 99
・これを満たすかどうかを判定

## 計算量
O(1) 判定を一回のみの計算量　入力サイズにも依存しない定数時間

## 学び
・2次元の範囲判定は「行」「列」を別々に考える
・a ≤ x ≤ b の連鎖比較は競プロで便利、早い
・「100マス」は +99 になる（端を含む個数の考え方、最初間違えたので今後注意）
